## 1. 摘要

我提议做一个受控消融实验，在固定骨架、固定数据的前提下，隔离出**分词粒度**和**预训练目标**这两个因素对基因组语言模型记忆行为的影响。

核心交付物是一个**方差分解**：在不同模型之间观测到的记忆程度差异里，多少能归因于分词器，多少归因于训练目标，多少只是随机种子；以及这个差异幅度与我们 BCB '26 论文归因于*架构*的跨模型差异相比有多大。

这是一篇独立的会议论文，面向 AI/ML 会议，与 Alex 协同进行，而且它直接执行了已发表论文自己在讨论部分要求的实验。

## 4. 科学动机

### 4.1 已发表的比较同时变化了四样东西

BCB '26 论文把记忆行为的差异归因于**架构**。但四个被评估的模型同时在以下方面不同：

- 架构（Transformer 编码器 / Hyena 卷积 / StripedHyena 状态空间）
- **分词方式**（单核苷酸 / BPE / 字节级）
- 参数量（1290 万到 70 亿）
- **预训练目标**（因果的下一个 token 预测 / 掩码）

论文自己在第 6 节（局限与未来工作）里白纸黑字指出了这一点：

> "方法没有把这个因素与其他混淆变量分开，**包括参数量和分词策略**；要建立因果关系，需要在固定架构上做一个比较预训练目标的受控消融实验。"

所以这个因果论断目前尚未被识别，而论文自己也这么说。本提案就是提供这个缺失的实验。

### 4.2 分词是第二个未被检验的变量

Proposal 的 Aim 1 Rationale 断言，基因组数据的**"固定四字母表"**可能以领域无关评估捕捉不到的方式改变记忆动态。这个断言从未被检验过。

而它在这里是**可以检验的，且在自然语言中做不到**。同一串核苷酸，携带完全相同的信息，可以用字符 / 3-mer / 6-mer / BPE 四种粒度切分，内容毫无改变。在文本中，改变分词器会改变 token 的语义，而且词表会与语料共适应；字符级英文也不像 `{A,C,G,T}` 那样是无损且目标无关的表示。

这个实验给了论文一个 ML 读者从文本领域得不到的论断。

### 4.3 目前的比较是在不同单位下进行的

一个相关且独立的问题：困惑度是**按 token** 计算的。对于单核苷酸分词器，按 token 等于按核苷酸。但对于平均 token 跨越 *k* 个核苷酸的 BPE 分词器，按 token 的困惑度大致处在按核苷酸值的 *k* 次方这个尺度上。

Table 4 把两者放在同一根轴上。而 DNABERT-2 的换算系数**无法从已公开的信息中恢复**——它的平均 token 长度在 DNABERT-2 论文里任何地方都没有报告，而且会随语料变化。

这不是一个边角问题。它意味着已发表的跨模型差异里可能有一部分是单位造成的假象，而量化这一点正是分词轴的直接贡献。

## 5. 提议的论文

**工作标题：** *Architecture Was Not the Variable: Tokenization Granularity and Pretraining Objective Account for Memorization Differences in Genomic Language Models*

**论断：** 在固定骨架、固定数据、固定非嵌入参数预算和固定探针集的前提下，只改变分词粒度和预训练目标，所产生的记忆程度差异，其幅度可与文献归因于架构的差异相当。一旦按核苷酸而非按 token 来测量记忆，并在对齐条件下给掩码模型打分，掩码与因果之间的区别就是**掩码比例上的连续剂量反应**，而不是一个定性的架构属性。

**核心设计：** 在固定的 1290 万参数骨架上做 4 × 4 网格

- 分词器：字符 / 非重叠 3-mer / 非重叠 6-mer / BPE-4096
- 目标：因果自回归 / 掩码 15% / 30% / 50%
- 重复档位 r ∈ {1, 4, 8, 16} 在每次训练**内部**携带，零额外成本
- 3 个种子（主结果格点用 5 个）

约 90 次从零训练，全部在我们自己的控制之下。

**为什么结果是有保证的。** 方差分解无论落在哪一档都会产出一个数字：

| 结果 | 标题 |
|---|---|
| 分词器 + 目标复现了 ≥ 60% 的已发表跨模型差异 | 架构从未被识别出来；分词器和目标是一阶的隐私设计选择 |
| 30–60% | 该分解的首次量化；架构带有一个可测量的残差 |
| < 30% | **在受控条件下架构确实主导——这验证了已发表的结果** |

没有任何一个分支会颗粒无收。对一个六个月周期的第一篇论文，我认为这比"天花板更高但结论是二元的"更值得。

## 6. 方法学前置条件

在复现流程时，我发现评估代码中有若干测量细节需要在任何扩展工作构建其上之前先厘清——主要涉及 canary 序列在数据管线中如何被追踪、损失如何在 padding 位置上聚合、双向编码器如何被打分，以及基于排名的抽取判定的随机基线。

**我正在直接与 Alex 沟通这些问题。** 它们不影响本提案的可行性，因为本设计从零构建自己的模型族和自己的测量工具，而不是在已发表的数字之上做扩展。我在这里提及，只是为了说明校准工作已经计入时间线（第 1–6 周）。

基础审计还产出了两条值得作为正面收获提出的内容：

- **Bounded-prior membership privacy**（Alex 的扩展第 3 条）可追溯到 Li, Qardaji, Su, Wu & Yang（CCS 2013，*Membership Privacy: A Unifying Framework for Privacy Definitions*）以及 **Tramèr, Huang, Hubaux & Ayday（CCS 2015）**，也就是您自己的论文。我已经读过 CCS 2015 那篇并从中取得了正式表述，所以不再需要 PDF。相关定义列在下面的 §6.1。

  它是这项工作的正确报告标准：不同于 AUC，它是对机制的最坏情况保证，而不是对某一次攻击的平均情况测量。两个 AUC 相同的攻击，其最坏情况下的后验偏移可以相差很大，而且 AUC 根本无法转换成一条隐私保证。
- 均匀合成 DNA 的困惑度有一个精确的信息论下限 4.0（每核苷酸）。这给了我们自然语言所没有的东西：一个解析已知的"零记忆"数值，任何打分实现在被信任之前都可以用它验证。我打算把它做成代码库中的常驻正确性检验，并在论文里写成一个简短的方法学小节。

### 6.1 报告标准的精确表述

已对照 CCS 2013 原文核实（编号用 Li 等人的原始编号；CCS 2015 复述时重新编过号）。

**Positive membership-privacy（CCS 2013 定义 3.1）。** 机制 *A* 在 2^U 上的分布族 *D* 下提供 (*D*, γ)-PMP（γ ≥ 1），当且仅当对任意 S ⊆ range(*A*)、任意 D ∈ *D*、任意实体 t ∈ U：

```
(1)   Pr[t ∈ T | A(T) ∈ S]  ≤  γ · Pr[t ∈ T]
(2)   Pr[t ∉ T | A(T) ∈ S]  ≥  (1/γ) · Pr[t ∉ T]
```

**为什么必须有 (2)，用论文自己的算例说明。** 取 γ = 1.2，先验 Pr[t] = 0.85。只看式 (1)，后验上界是 0.85 × 1.2 = 1.02——这个界毫无约束力，对手可以达到 100% 确信，而名义上还满足一个"很强"的 γ。式 (2) 把 Pr[¬t | S] 下界卡在 0.15 / 1.2 = 0.125，于是后验被限制在 0.875。两式缺一不可，合起来给出

```
(3)   Pr[t | S]  ≤  min{ γ · Pr[t],  (γ − 1 + Pr[t]) / γ }
```

**充分条件（引理 3.2）。** 若对任意满足 0 < Pr[t] < 1 的 t 和任意输出事件 S 都有 Pr[S | t] ≤ γ · Pr[S | ¬t]，则 *A* 提供 ({D}, γ)-PMP。这是机制设计者实际能控制的形式，也是基于 loss 的攻击可以挂靠的接口。

**与差分隐私的桥梁（定理 4.8）。** *A* 满足 ε-bounded DP **当且仅当**它提供 (D_B, e^ε)-PMP，其中 D_B 是有界互独立分布族——给每个实体分配一个独立的入选概率 p_t，并限定数据集大小固定。

**有界先验的松弛（CCS 2015 定义 8）。** 对 0 < a ≤ b < 1，子族 D_B[a,b] ⊆ D_B 把对手的先验限制在 Pr[t] ∈ [a, b] ∪ {0, 1}。在这个更弱也更现实的对手模型下，用比 (ln γ)-DP **更弱**的隐私预算即可达到同样的 γ-PMP；那篇的引理 3 给出逐个体的紧参数 γ(t) < γ。这一条对我们直接有用：它把"我们默认对手有多少背景知识"从一个隐藏假设变成一个写明的区间。

**这对论文的价值。** 我会在 TPR@低FPR 之外同时报告 γ，并明确写出 [a, b]，这迫使威胁模型具体化：在查询模型之前，对手对某个特定个体属于微调队列这件事能有多大把握？在基因组场景中这可以从队列规模和招募范围论证——而这恰恰是 AUC 默不作声的那类假设。两个 AUC 相同的攻击，最坏情况下的后验偏移可以相差很大，而且 AUC 根本无法转换成一条保证。

**有一个问题想请教您**（见 §11.2）：CCS 2015 的表述把 PMP 应用在被发布的 GWAS 统计量上。迁移到被查询模型给出的逐序列 loss，机制输出 *S* 的含义变了，而且对手可以自己选择查询内容。当时您是否考虑过这方面的细节？

## 10. 与 Aim 1 其余部分的关系

本论文刻意**不**占用 proposal 中最大的几项未执行内容。以下仍然开放：

- **Aim 1.2（防御）** —— 已确认无人认领。我希望把它作为第二篇。有一点需要说明：在 1290 万参数、从零训练的规模上，下游效用这根轴可能无法产生可测量的变化，那样隐私-效用权衡图就没有信息量。建立一个可用的效用评估协议是前提，我希望在投入之前先把这件事摸清楚。
- **属性推断与亲属泄漏。** Proposal 把 GLM 隐私的动机部分建立在遗传性上——一段被记住的序列会暴露从未同意过的亲属。已发表的工作中没有任何内容测量这一点。1000 Genomes 高覆盖版提供了 602 个完整的三人家系，完全开放获取，无需数据申请，因此这是可以直接检验的。我认为这是目前可用方向中天花板最高、也最不容易被 NLP 组抢先的一个，但它是数据工程优先的，而那正是我背景最薄弱的领域，所以我提议把它排在第三篇而不是第一篇。**如果您认可，我希望现在就把这个方向占下来**，并可以写一页的方向草图。
